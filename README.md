## 📌 Assignment Overview

This repository contains my solutions to the **Problem Solving with TypeScript & OOP** assignment. The goal of this assignment is to strengthen my understanding of TypeScript fundamentals, generics, type safety, asynchronous programming, and object-oriented programming.

### 📚 Topics Covered

- Basic Types & Type Annotations
- Optional, Default & Rest Parameters
- Union Types & Type Narrowing
- Readonly Tuples
- Interfaces & Generics
- Generic Constraints (`keyof`)
- Promises & Asynchronous Programming
- Object-Oriented Programming (OOP)
- Classes, Inheritance & Access Modifiers
